Ohm's Law Calculation

                Formula  : R = (Vs - Vf) / If
                Vs       : 9V (Source)
                Vf       : 2V (LED forward voltage)
                If       : 0.015A (15mA target 20mA (max))
                __________________________________________

                Result   : (9-2) / 0.015 =466.67 ohm
                Standard : 470 ohm

I Learned in this project

1) Series Circuits have a single current path

One open connection kills all LEDs simultaneously

2) Resistors are never optional

Without one, current is 70x the LEDs rated maximulm-instant destruction

3) Voltage divides in series, current stays constant

3 * 2V = 6V across LEDs, remaining 3V across resistor

4) Always calculate R before connecting power

R = (Vs - Vf) / If - memorise this formula
